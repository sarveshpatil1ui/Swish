# SWISH React Prototype

## Requirements
- Node.js 18+ (Node 20+ recommended)
- VS Code

## Setup
Open this folder in VS Code, then run:

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.

## Dependencies
Runtime:
- react
- react-dom
- react-router-dom

Development:
- vite
- @vitejs/plugin-react

You do NOT need to separately install these packages if you run `npm install`; package.json installs them automatically.

## If you get a stale Vite/browser error
Stop the server with Ctrl+C, then run:

```bash
npm install
npm run dev
```

If needed, hard-refresh Chrome with Ctrl+Shift+R.
